# Real-time multi-region Loki query

**Version:** v0.2.22-beta  
**Scope:** Query multiple regional Loki endpoints in one pass — CLI merge + optional Grafana datasources.

Complements hot retention ([17-LOG-ARCHIVE-GUIDE.md](17-LOG-ARCHIVE-GUIDE.md)) and DR exports ([21-OBSERVABILITY-LONG-TERM-ARCHIVE-GUIDE.md](21-OBSERVABILITY-LONG-TERM-ARCHIVE-GUIDE.md)).

---

## When to use

| Scenario | Tool |
|----------|------|
| Incident spanning US + EU stacks | `scripts/query-loki-multi-region.sh` |
| Grafana Explore per region | `scripts/write-grafana-loki-regions.sh` |
| Staging readiness | Provider probes hit each Loki `/ready` when regions configured |

This queries **live Loki** in each region — not Glacier export NDJSON (use export script + restore for cold archives).

---

## Configuration

```bash
# Comma-separated region=name=url pairs (or bare URLs → region-1, region-2, …)
LOKI_QUERY_REGIONS=us-east=http://loki-us-east.internal:3100,eu-west=http://loki-eu-west.internal:3100

# Shared query window
LOKI_QUERY='{service="api"} | json | level="ERROR"'
LOKI_QUERY_HOURS=6
LOKI_QUERY_LIMIT=5000
LOKI_QUERY_OUTPUT=ndjson   # ndjson | table | summary
```

Primary single-region dev still uses `LOKI_URL` when `LOKI_QUERY_REGIONS` is unset.

---

## CLI merged query

```bash
export LOKI_QUERY_REGIONS=us-east=http://127.0.0.1:3100,eu-west=http://127.0.0.1:3101
./scripts/query-loki-multi-region.sh

# Quick counts per region
LOKI_QUERY_OUTPUT=summary ./scripts/query-loki-multi-region.sh
```

Output NDJSON includes `region`, `timestamp_ns`, `labels`, and `line` — sorted by time across regions.

---

## Grafana datasources

```bash
export LOKI_QUERY_REGIONS=us-east=http://loki-us:3100,eu-west=http://loki-eu:3100
./scripts/write-grafana-loki-regions.sh
./scripts/write-prometheus-token.sh   # if not already done
docker compose -f docker-compose.yml -f docker-compose.monitoring.yml up -d
```

- Default datasource **Loki** (`monitoring/grafana/provisioning/datasources/loki.yml`) — local / primary stack.
- Extra regions → **Loki (us-east)**, **Loki (eu-west)** from `monitoring/grafana/provisioning/datasources/loki-regions.yml` (generated by write script).
- Federated dashboard + ruler fan-out: [33-FEDERATED-GRAFANA-LOKI-RULER-GUIDE.md](33-FEDERATED-GRAFANA-LOKI-RULER-GUIDE.md)

In Explore, pick a regional datasource or run LogQL on each; merged CLI is for cross-region timelines.
