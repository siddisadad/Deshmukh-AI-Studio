# 12 — Team Structure

For a trainee batch, divide responsibilities. Rotate later so everyone gets practical exposure.

## Team A — Backend

- FastAPI
- SQLAlchemy
- MySQL
- Authentication
- APIs

## Team B — Frontend

- React
- UI
- Forms
- API integration
- Dashboard

## Team C — QA

- Postman
- Test cases
- Bug reports
- Regression testing

## Team D — DevOps

- GitHub
- Docker
- CI/CD
- Deployment

## Collaboration norms

- One issue → one feature branch → one PR  
- Backend and frontend agree on API contracts before UI wiring  
- QA owns a Postman collection and regression checklist per sprint  
- DevOps does not block Month 1 — join fully in Month 3 platform work
